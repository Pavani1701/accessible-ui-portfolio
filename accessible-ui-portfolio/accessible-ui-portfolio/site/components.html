Component library

Reusable, themeable components. Every interactive pattern follows the WAI-ARIA Authoring Practices keyboard model and has been checked with axe-core and a screen reader.

Buttons and status messages

Buttons have 44px minimum targets. The “Save draft” action reports its result in a polite role="status" live region, so screen reader users hear the confirmation without losing focus.
